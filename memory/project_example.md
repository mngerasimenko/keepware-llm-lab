`demo-api` - учебный REST-сервис (условный пример для этого репозитория). Стек: Fastify, Postgres, миграции через `node-pg-migrate`. Аутентификация - JWT в httpOnly-cookie.

Текущая цель: довести покрытие эндпоинтов интеграционными тестами до разумного минимума перед первым релизом. Ограничение: внешние вызовы в тестах мокаем, реальную БД поднимаем в контейнере на CI.

Это вымышленный проект - никаких реальных данных, хостов или секретов он не описывает.
