# Как мы наполняем этот репозиторий

Репозиторий публичный, и главное правило здесь одно.

## Правило санитизации (обязательное)

**Сюда попадает только синтетика.** Каждый файл - обезличенный пример, а не выгрузка из рабочего окружения. Через это правило проходит любое добавление, без исключений.

Запрещено класть в репозиторий:

- реальные данные проектов, клиентов, пользователей (152-ФЗ - персональные данные не выкладываем никогда);
- любые секреты: токены, ключи, пароли, строки подключения, содержимое `.env`;
- внутреннюю стратегию, финансовые цели, данные по конкурентам, внутренние имена/клички систем;
- реальные пути, хосты, IP, домены внутренней инфраструктуры.

Если пример хочется сделать «как настоящий» - выдумайте нейтральный демо-проект (условный `demo-api`) и наполните его правдоподобно, но полностью вымышленно.

## Чек перед коммитом

1. Открыть diff целиком и глазами проверить каждую строку на предмет утечки из списка выше.
2. `grep` по типовым маркерам секретов (`token`, `secret`, `password`, `api_key`, `BEGIN PRIVATE KEY`) - должно быть пусто.
3. Спросить себя: если это увидит посторонний, узнает ли он что-то о реальных проектах или людях? Если да - переписать на синтетику.

## Как добавить память

1. Создать файл в `memory/` по формату из [`README`](./README.md#формат-файла-памяти).
2. Добавить одну строку-указатель в `memory/MEMORY.md`.
3. Прогнать чек санитизации выше.

## Как добавить скил или промпт

Пока разделы `skills/` и `prompts/` - заготовки. Наполняем по мере того, как приём отработан на проектах и обезличен. Тот же чек санитизации.
