# prompts/

Промпт-заготовки для типовых задач вокруг файловой памяти.

- [`setup-memory.md`](./setup-memory.md) - дать своему агенту, чтобы он сам развернул файловую память в новом проекте: создаёт `memory/`, заводит стартовые факты по проекту, подключает индекс импортом и проверяет границу git.

Новое добавляем по мере обкатки и обезличивания под правило санитизации ([`../CONTRIBUTING.md`](../CONTRIBUTING.md)).
